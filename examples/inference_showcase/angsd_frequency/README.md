# ANGSD: genotype likelihoods are not hard calls or posterior probabilities

**2026-11-03 · Inference showcase · Original deterministic synthetic example**

This runs the actual **ANGSD 0.941** command-line program to estimate a
population ALT-allele frequency from supplied genotype likelihoods. It is a
small inference-mechanism demonstration, not a sequencing benchmark or a
claim that one estimator is always more accurate.

## Estimand and input

The estimand is the population frequency `p` of the specified ALT allele,
conditional on supplied likelihoods and a diploid Hardy–Weinberg model.
It is **not** the realized fraction of ALT copies in these individuals.
The input is eight constructed biallelic sites, each with 20 diploids,
in [`synthetic_input.vcf`](synthetic_input.vcf). REF is A and ALT is C.
The VCF GL field contains log10 likelihoods for AA, AC and CC, in that order.
No reads, genotype calls, biological sample data, or private research are used.
There is no random seed because construction is deterministic.

For independent individuals the likelihood is

```text
L(p) = product_i [L_i(AA)(1-p)^2 + L_i(AC) 2p(1-p) + L_i(CC)p^2].
```

ANGSD's `-doMaf 1` uses an EM algorithm with fixed alleles. With this VCF input,
the output columns called `major` and `minor` retain REF and ALT respectively.
Consequently `knownEM` here is **ALT frequency**, and can exceed 0.5; we do not
fold it into the minor-allele frequency. The example calls ANGSD itself and
fails if its executable, version, output orientation, or retained sites do
not match expectations. There is no substitute inference implementation.

## A hard-call list hides likelihood information

At each of the two main sites, every individual has the same constructed
likelihood triple. These are valid relative likelihoods for hypothetical
observations, deliberately selected for a transparent analytical optimum.
They are **not generated by a realistic sequencing-read model**.

| Site | Linear GL: AA, AC, CC | Hard-call ALT frequency | Actual ANGSD estimate | Exact likelihood maximum |
| --- | --- | ---: | ---: | ---: |
| Symmetric | 0.2, 1, 0.2 | 0.5 | 0.499995 | 0.5 |
| Asymmetric | 0.8, 1, 0.2 | 0.5 | 0.199960 | 0.2 |

All 20 maximum-likelihood genotype calls are AC at both sites. Nevertheless,
the full likelihood estimates differ: evidence favoring AA over CC matters
although neither is the individually best genotype. There is no supplied
"true population frequency" in this construction, so this does not establish
bias or accuracy against biological truth.

For a repeated triple `(a,1,b)`, with `0<a,b<1`, the individual marginal
likelihood is a strictly concave quadratic:

```text
q(p) = a + 2(1-a)p + (a+b-2)p^2
p*   = (1-a)/(2-a-b).
```

Because `q(p)>0`, repeating it 20 times preserves its unique maximum. This
closed-form oracle is independent of ANGSD's EM iterations. At the asymmetric
site the log-likelihood loss from using hard-call frequency 0.5 rather than
0.2 is **2.266573706** natural-log units: `20 log(0.84/0.75)`.

Normalizing `(0.8,1,0.2)` to sum to one and treating it as genotype posterior
probabilities would give mean dosage frequency **0.35**, not 0.2. Normalization
alone does not supply the HWE genotype prior. The 0.35 calculation corresponds
to imposing a uniform prior over the three genotypes; it is not this population
likelihood estimate. We use the GL input path, not ANGSD's posterior-input path.

## Controls and actual output

[`sample_output.json`](sample_output.json) records the actual run, including:

- Reversing likelihood triples gives ALT estimate **0.799963**, close to exact
  0.8. It is not folded to 0.2.
- Rescaling each individual's three GLs by its own positive constant preserves
  the estimate **0.199960**. Absolute likelihood normalization is immaterial.
- Replacing half the individuals with `(1,1,1)` leaves estimate **0.199960**
  and reduces ANGSD's informative-individual count to **10**.
- An all-uninformative site has a constant likelihood for every `p` and is
  omitted by ANGSD. An omitted site must not be interpreted as zero frequency.
- Near-certain all-reference and all-ALT controls return **0 and 1 at printed
  precision**. This is not a confidence statement.

The 32 tests include exact rational enumeration of all latent genotype
assignments for up to four individuals; a separate 80-digit Decimal check;
closed-form curvature and optimum checks; scaling, reversal, subject-order,
missing-information and boundary controls; and **all 55 genotype-count tables
for one through five diploids**. For the latter, positive likelihoods of
`1e-12` replace exact zeros, and results approach the known dosage fraction
within `1e-6`. Input and checked output are reproduced byte for byte.

ANGSD 0.941 uses float EM intermediates, a starting frequency of 0.001,
at most 100 iterations, and an absolute successive-iterate stopping threshold
of `1e-5`. That threshold is
**not a bound on distance to the likelihood optimum**. Here the two asymmetric
estimates are within `5e-5` of their analytical optima, and their sum differs
from 1 by `7.7e-5`. Tests explicitly allow these numerical errors rather than
silently claiming exact symmetry or exact optimization. See the pinned
[`abcFreq.cpp`](https://github.com/ANGSD/angsd/blob/b3099ed756e7aff87d2d1dd4fd30cdf36998380b/abcFreq.cpp).

## Reproduce

Linux x86-64 reference environment: **CPython 3.14.5, ANGSD 0.941**, source
revision `b3099ed756e7aff87d2d1dd4fd30cdf36998380b`, and **HTSlib 1.24**.
No third-party Python dependencies. A C/C++ toolchain, make, curl and zlib
headers are needed. The installer downloads official source archives, verifies
SHA-256 before extraction, and builds only in ignored `.cache/angsd-af`.
It does not install globally. Archive hashes are recorded in
[`install.py`](install.py); the local build stamp also records the binary hash.
HTSlib network codecs and optional compression dependencies are disabled.

From the repository root:

```sh
python -c "import platform; assert platform.python_version() == '3.14.5'"
python -m examples.inference_showcase.angsd_frequency.install
python -m unittest discover -s examples/inference_showcase/angsd_frequency -v
python -m examples.inference_showcase.angsd_frequency.demo --check-sample
```

The actual CLI command used by the Python adapter is equivalent to:

```sh
.cache/angsd-af/build/angsd-b3099ed756e7aff87d2d1dd4fd30cdf36998380b/angsd \
  -vcf-gl examples/inference_showcase/angsd_frequency/synthetic_input.vcf \
  -doMaf 1 -nThreads 1 -out /tmp/angsd-frequency
```

The dedicated CI job builds the pinned tool and checks the eight-site output
and all controls. Inference uses one thread and has no randomized optimizer.

## Assumptions and limitations

- Independent unrelated diploids from one population, HWE genotype weights,
  two specified alleles, and correctly specified likelihoods are assumed.
- No genotype errors are estimated here; the input GLs are treated as given.
  Population structure, inbreeding, contamination, mapping bias, incorrect
  likelihood calibration and missingness related to genotype can invalidate
  this simple model.
- The sites are separately analyzed illustrative cases. There is no read
  alignment, SNP discovery, LD model, ancestral polarization or SFS inference.
- No uncertainty interval, posterior probability for `p`, empirical accuracy,
  coverage claim, or population-genetic history is inferred.
- Numerical agreement checks implementation behavior on chosen cases, not
  suitability of this model for any real population.
