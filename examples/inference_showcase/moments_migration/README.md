# moments: migration inference depends on the assumed split time

An original CPU example using **moments-popgen 1.6.1** to estimate symmetric
migration from a synthetic joint site-frequency spectrum (SFS). The tool
computes expected spectra through moment equations and fits their shape. This
is actual demographic inference in a deliberately narrow model, not a statistic
renamed as a demographic estimate or a reproduction of the paper's analyses.

## Estimand and input

The estimated parameter is **M = 2 × Nref × m**, where `m` is the fraction of
each descendant population replaced by migrants from the other population per
generation. Migration is continuous and symmetric. `Nref` is the ancestral
diploid effective population size; both descendant sizes are held at `Nref`.
The ancestral population starts at neutral mutation-drift equilibrium and splits
`T` units ago, where one unit is **2 × Nref generations**. **T is supplied, not
estimated.** An absolute migration fraction requires an external `Nref`.

The observed input is a **13 × 13 unfolded joint SFS** for **12 haploid
chromosomes per population**. Entry `[i,j]` counts sites with `i` derived copies
in population 1 and `j` in population 2. Only globally monomorphic corners
`[0,0]` and `[12,12]` are excluded; private polymorphisms and fixed differences
remain in the fit. Ancestral alleles and sample sizes are assumed known.

[synthetic_sfs.json](synthetic_sfs.json) contains **2,665 segregating sites**.
It was generated by independent Poisson draws around `theta × expected_sfs`,
with `M=1`, `T=0.5`, `theta=500`, and NumPy **PCG64 seed 20261027**. The model
integrates 20 chromosomes per population, then projects down to 12. This is a
synthetic count experiment, not a simulated genome, linked sequence, real
sample, or private dataset. Generation metadata are separate from the counts;
`fit()` accepts counts and explicitly assumed model settings only.

## Fitting and numerical controls

At each candidate `M`, moments computes a model spectrum `f` at `theta=1`.
The mutation scale is profiled out:

```text
theta_hat = sum(observed_ij) / sum(f_ij)
profile_log_L = sum_ij [observed_ij * log(theta_hat*f_ij)
                       - theta_hat*f_ij - lgamma(observed_ij + 1)]
```

This is `moments.Inference.ll_multinom`: a Poisson likelihood at the optimal
scale, with the same shape optimum as a multinomial fit. Printed likelihoods
retain the Poisson constants. For a target of `L` sites, the conventional scale
is `theta = 4*Nref*mu*L`; this example does not infer `Nref`, `mu`, or `L`.

`moments.Inference.optimize_log_fmin` optimizes log `M` from three fixed starts
`[0.2,1,4]`, within `[0.01,10]`. The wrapper rejects failed optimization,
solutions close to the bounds, and estimates disagreeing by more than 0.001.
A coarse log-spaced likelihood grid and nearby points provide further checks;
these checks do not prove global optimality.

The default timestep factor is 0.02. Eight extra chromosomes per population
are integrated before projection (20 to 12). Repeating with 16 extra
chromosomes (28 to 12) probes sensitivity to the finite moment closure;
halving the timestep probes time integration error. Neither test establishes
complete numerical convergence.

The older-time assumption changes `M` and the nuisance scale. Its worse fit
for this particular seed does not validate a historical reconstruction.
Fixing migration to zero gives a profile log likelihood of **-976.766006**
on these counts. That comparison is descriptive; no significance level,
likelihood-ratio calibration, or model-selection guarantee is claimed.

Halving the timestep changes fitted `M` by **0.001720%**. Increasing the
internal spectrum changes it by **0.139832%**, showing visible closure
sensitivity despite agreement among optimizer starts. Noiseless recovery uses
the same solver and fractional expected counts: it checks plumbing and
optimization, not independent demographic accuracy. Its likelihood is not
comparable with the likelihood for the noisy counts.

## Reproduce

From the repository root, use a separate **CPython 3.12.11** environment:

```sh
python3.12 -m venv .venv-moments
. .venv-moments/bin/activate
python -c "import platform; assert platform.python_version() == '3.12.11'"
python -m pip install --require-hashes -r examples/inference_showcase/moments_migration/requirements.lock
export OPENBLAS_NUM_THREADS=1
python -m unittest discover -s examples/inference_showcase/moments_migration -v
python -m examples.inference_showcase.moments_migration.demo --check-sample
```

The [hash lock](requirements.lock) pins all eight distributions, including
**moments-popgen 1.6.1, NumPy 2.3.5, and SciPy 1.16.3**. The package declares
`scipy<1.17`; this environment is intentionally isolated from other examples.
Install **moments-popgen**: the PyPI package named `moments` is unrelated.
Only CPU arithmetic is used; no model weights, external genetic data, or
service are needed. CI executes the real tool and the checks below.

```sh
python -m examples.inference_showcase.moments_migration.demo --generate-input > /tmp/moments-input.json
diff -u examples/inference_showcase/moments_migration/synthetic_sfs.json /tmp/moments-input.json
python -m examples.inference_showcase.moments_migration.demo --time 0.75
```

The **22 tests** cover an independent `1/i` equilibrium oracle, a
hypergeometric instantaneous-split oracle, neutral marginal stationarity,
population exchange symmetry, lack of migration information at `T=0`, correct
corner masking, exact seeded input regeneration, an independent scalar Poisson
likelihood, three starts, neighboring/grid likelihoods, zero-migration control,
noiseless recovery, doubling-count invariance, time-assumption sensitivity,
timestep and spectrum-size checks, failure handling, invalid inputs, truth
separation, sample regression, and CLI behavior. Sample floats allow absolute
and relative tolerance `2e-4` across CPU libraries; integers, versions, and
structure must match exactly. These are regression tolerances, not confidence
intervals. Analytical checks have much tighter tolerances stated in the tests.

## Assumptions and limitations

- Neutral, infinite-sites, constant-size diploid populations, equilibrium
  ancestry, instantaneous split, and continuous symmetric migration. No
  selection, changing size, pulse admixture, ancestral structure, ancestral-state
  error, ascertainment, or missing calls are modeled.
- Only migration is optimized; time and relative sizes are fixed. The example
  does not jointly identify a full demographic history or estimate absolute
  per-generation migration. At `T=0`, all migration values give the same model;
  fitting at zero time is explicitly rejected.
- Independent Poisson bins are the data-generating assumption here. Real
  linked genomic variants are correlated, making the usual SFS likelihood a
  composite likelihood. No calibrated uncertainty or bootstrap is provided.
- One seed and one model are not a bias/accuracy study, biological discovery,
  comparative benchmark, or evidence of superiority over another tool. The
  date-based seed was fixed before seeing the result.
- The enlarged-spectrum check and noiseless check still use moments. They do
  not independently validate the migration closure or real-data robustness.
