# SPARE: write strength is not memory capacity

An original educational implementation of the compact-state update in
[Wan, Zheng and Chen, *SPARE: Fast Linear Attention Decoding with Compact Recurrent States*](https://arxiv.org/abs/2611.07552v1),
a **November 5, 2026 preprint**. The source mechanism is Eqs. 4–5 and 8–10;
Theorem 1 gives the subspace-invariance condition. No upstream code is copied.

## Mechanism implemented

A supplied orthonormal key basis P compresses keys and queries to z=Pᵀk and
u=Pᵀq. The recurrent state C has value dimension by retained rank. We implement:

```text
rho   = dot(z, z)
gamma = min(1 / max(rho, epsilon), cap)
C_new = alpha*C + beta*gamma*(v - alpha*C*z)*z^T
output = C_new*u
```

Keys have unit norm before projection and are **not renormalized afterwards**.
Multiplying the update by z gives effective write strength beta*gamma*rho.
The numerical floor and cap can keep that below beta. Without either limit
active, compensation restores beta along the current projected key, not all
information discarded by projection. The original paper supplies calibrated
bases and rank allocation; this example supplies P directly.

## Constructed experiment and actual output

We use a scalar value, two-dimensional keys, P=(1,0)ᵀ, zero initial state,
and boundary-control gates alpha=beta=1. These closed boundaries are continuous
limits of the paper's interior gates, chosen for transparent arithmetic.
The implementation also tests interior gates. epsilon=1e-8 and cap=16 are our
illustrative settings, not a claimed reproduction of a paper experiment.

A first key (0.6,0.8) writes value 1. Its projected squared norm is 0.36.
The uncompensated same-key read is **0.36**; compensation yields **1**.
With cap=2, or floor epsilon=0.5, the read is only **0.72**.

Next write value −1 at (0.8,−0.6). These two original keys are orthogonal,
so dense delta memory retrieves **[1,−1]** after the two writes. In the
one-dimensional projection they share a direction. Compensated compact memory
retrieves **[−0.75,−1]**. The current write succeeds while the old association
is lost. A completely discarded key (0,1) gives zero read despite compensation.
These numbers are generated by `demo.py`, not transcribed from the paper.

## Reproduce

Use CPython **3.14.5**, standard library only; no installs, GPU, data, model
weights, network calls or paid services. From the repository root:

```sh
python -c "import platform; assert platform.python_version() == '3.14.5'"
python -m unittest discover -s examples/spare_projection -t . -v
python -m examples.spare_projection.demo
python -m examples.spare_projection.demo --check-sample
```

The demonstration is deterministic, with no random seed. A test uses seed
20261113 to choose rational sequences; it compares 180 successive updates
against a separate exact-Fraction matrix-transition implementation.
`sample_output.json` is rounded to nine decimal places and checked byte for byte.

The 24 tests additionally check invariant-subspace exactness, a full-rank rotated
basis, the read identity, cap/floor effects, zero projection, sign invariance,
value linearity, nonmutation, boundary gates, malformed inputs and CLI output.
Numerical comparisons use eleven decimal places. The exact oracle is test-only;
production recurrence does not reconstruct dense states.

## Limits

This is a small supplied-input kernel, not a trained model or full SPARE
implementation. It omits key PCA, heterogeneous ranks, projection fusion,
convolutions, GPUs and performance measurements. It makes no model-quality,
latency, memory-throughput or hardware speedup claim. The chosen collision
illustrates possible information loss, not its incidence in real models.
Exact recovery is tested only under the stated invariant-subspace conditions.
