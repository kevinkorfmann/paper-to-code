# Fluctuating selection: arithmetic mean fitness can point the wrong way

An original SLiM experiment with two clonally reproducing types. Type A has
relative parental reproductive weight 1.8 in odd generations and 0.4 in even
generations; B always has weight 1. The arithmetic mean for A is **1.1**, yet its
geometric mean is **sqrt(0.72) ≈ 0.8485**. Its frequency declines across complete
cycles in the deterministic model. Replacing its varying weights by their
arithmetic mean reverses the predicted direction.

This is an educational mechanism demonstration, not a reproduction of a paper,
an empirical fitness estimate, a general theorem about sexual diploids, or a
simulation of stochastic environmental change. The environment here alternates
on a fixed schedule. Randomness comes from reproduction.

## Run

Use CPython **3.14.5**, standard library only, and SLiM **4.0.1 / Eidos 3.0.1**.
The repository CI builds the checksum-pinned official SLiM source; see
[the workflow](../../../.github/workflows/tests.yml). Put `slim` on PATH.
From repository root:

```sh
python -m unittest discover -s examples/slimulations/fluctuating_selection -v
python -m examples.slimulations.fluctuating_selection.demo
python -m examples.slimulations.fluctuating_selection.demo --check-sample
```

The demo also accepts `--slim /path/to/slim`. The Python `run()` function exposes
N, initial A count, number of generations, two weights, replicates and seed.
Supported oracle size is deliberately capped at N=200 and 40 generations.
No dependency installation or network access is needed to run the example once
SLiM and Python are available. Full checked trajectories are in
[`sample_summary.json`](sample_summary.json), generated by actual SLiM runs.

## Model and exact controls

Each of 512 independent populations has N=100 **clonal individuals**, initially
50 of each type. SLiM represents them as homozygous diploids that clone with
probability one. Both homologues carry the same neutral marker in type A, and
only the parental reproductive weight differs. There are N independent offspring
sampling units, not 2N independent gametes. There is no mutation, migration,
sexual reproduction, recombination, overlapping generation or density change.
No replicate is excluded after fixation or loss. Those states are absorbing.

With K A clones, the conditional offspring probability is

`q = K*w / (K*w + N-K)` and `K_next | K ~ Binomial(N, q)`.

The Python oracle propagates the entire distribution over K=0,...,N through
these transition matrices. It is the exact finite model evaluated numerically
in double precision, not an approximation substituting mean frequency into q.
Tests independently enumerate every ordered two-generation offspring path for
N=2,3,4 with rational arithmetic. Additional tests verify binomial moments,
neutral mean and drift variance, deterministic odds, absorbing endpoints,
input parsing, schedule timing, replay and full checked output.

For an infinite population, `odds_next = w * odds`. Every two-generation cycle
therefore multiplies A:B odds by `1.8*0.4 = 0.72`. Starting at p=1/2, after six
cycles, `p = 0.72**6/(1+0.72**6) = 0.122278899`. Reversing the order or using
constant weight sqrt(0.72) gives the same deterministic endpoint. It does **not**
give the same finite-population distribution: stochastic loss can happen between
the two environmental phases. The finite oracle quantifies this distinction.

| Constant arithmetic mean 1.1 | 0.748085937 | 0.005937234 | 0.747938923 | 0.758362376 |
| Constant geometric mean sqrt(0.72) | 0.132207031 | 0.003909584 | 0.131564090 | 0.122278899 |
| Neutral 1.0 | 0.484003906 | 0.007883494 | 0.500000000 | 0.500000000 |

Seeds are 202611090–202611094 in the table order. The simulation means fluctuate
around the exact finite expectations. In particular this batch does not resolve
the small difference between alternating and reversed mean endpoints. The exact
oracle, not the sample ranking, establishes that their distributions differ.
A broad six-standard-error regression guard checks each mean against its oracle;
it is not a formal significance or calibration test.

## Interpretation and sources

The result is about **relative reproductive weights across generations**. It
is not a claim that every individual with high arithmetic mean offspring number
loses, or that geometric means alone describe arbitrary populations. Sex,
dominance, environmental correlations, frequency dependence and density regulation
can change the argument. Nor does a 12-generation mean establish fixation odds.

- Gillespie, J.H. (1973). [Natural selection with varying selection coefficients –
  a haploid model](https://doi.org/10.1017/S001667230001329X), *Genetics Research*
  21:115–120. Primary source for geometric-mean selection in an infinite haploid
  population with random environments. Our fixed alternating, finite clonal
  model illustrates a related principle and does not reproduce its diffusion model.
- Haller, B.C. & Messer, P.W. (2023). [SLiM 4: Multispecies Eco-Evolutionary
  Modeling](https://doi.org/10.1086/723601). Simulator reference.
